# nodejs express ruter

## Starte prosjektet
start med 
```bash
npm init -y
```

## Sett type module
Åpne `package.json` og endre type slik:
```text
type:"module"
```

## Installere moduler når package.json er satt opp
```bash
npm i
```
Kommandoen sjekker alle dependencies i `package.json` og installerer dem.
